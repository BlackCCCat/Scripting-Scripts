# Provider icon sources

The runtime PNG assets are embedded in `utils/provider_icons_data.ts`. These source assets preserve recognizable vendor marks on a transparent canvas and fit the dashboard's shared icon surface.

- Abacus AI: official favicon-derived colors and four-slider mark. The tile was removed and the mark was redrawn as vector paths from the supplied glyph.
- Codebuff: official [favicon](https://codebuff.com/favicon/apple-touch-icon.png); black launcher tile removed, sparkle mark retained.
- Kiro: official [Kiro SVG icon](https://kiro.dev/icon.svg); purple tile removed, ghost mark retained.
- xKiro: official [xKiro SVG icon](https://xkiro.com/images/logo/v2/xkiro-icon-color-small.svg); tile and outline removed, X/K mark retained.
- LiteLLM: official [monogram](https://cdn.prod.website-files.com/69eb241da3f923869c226875/6abe9abc2367e992580e9e96_litellm-monogram-blue.svg); standalone car glyph extracted from its tile.
- Synthetic: official [favicon SVG](https://synthetic.new/favicon.svg).
- T3 Chat: official [site icon](https://t3.chat/icon.png); magenta tile removed, speech-bubble mark retained.
- Xiaomi Coding Plan: MI glyph isolated from the existing project icon; transparent mark colored with Xiaomi orange.
- Anthropic: official [Safari pinned-tab SVG](https://www.anthropic.com/images/icons/safari-pinned-tab.svg), with no white background.

Derived PNGs have vector counterparts in this folder for the dashboard-specific transparent marks. Brand marks remain their respective owners' trademarks.

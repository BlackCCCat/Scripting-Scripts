## 当前版本

- 新增 Telegram 贴纸包读取、预览、选择下载和本地缓存。
- 默认只读取并下载静态贴纸，避免动态贴纸和视频贴纸在键盘环境中造成不稳定。
- 支持同名贴纸包重新添加时追加合并，不再覆盖已有贴纸。
- 支持删除贴纸、删除空贴纸组，并同步清理本地贴纸目录。
- 键盘支持按贴纸组切换、最近使用分组、左右滑动切换分组。
- 键盘贴纸点击后复制图片到剪贴板，并保留系统键盘切换、回到主界面和指定脚本切换按钮。
- 设置页用于配置 Bot Token 和可选的目标键盘脚本名称。
- 已移除 ShareSheet 相关实验逻辑和 GIF 转换流程。

## 说明

- 当前版本聚焦静态贴纸键盘体验。
- Telegram `.tgs` 动态贴纸和 `.webm` 视频贴纸不会默认导入。
- iOS 自定义键盘无法稳定把图片或文件直接粘贴到宿主 App 光标处，当前采用复制到剪贴板的方式。

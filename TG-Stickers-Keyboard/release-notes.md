## 本次更新
- 设置页新增“下载动态贴纸”开关，默认关闭。
- 开启后会在读取 Telegram WEBM 视频贴纸时生成 GIF 预览，读取完成即可播放动画。
- 主脚本恢复使用 `Image filePath` 直接加载 GIF，与早期版本的小图显示方式保持一致。
- 下载的动态贴纸可在主脚本中播放，但不会进入自定义键盘，降低键盘崩溃风险。
- 点击已添加贴纸组的名称，可使用原链接重新读取并选择追加贴纸。
- 贴纸编辑页右上角改为操作菜单，支持删除、保存到 TG-Stickers 相簿和清除已保存贴纸。
- 清除相册贴纸会删除 TG-Stickers 相簿内的实际照片资产，并在相簿为空后删除相簿。
- 优化键盘滚动，贴纸间隙和背景区域也可以开始拖动。

## 最近更新
- 复制粘贴不再错误使用缩略图
- 新增 Telegram 贴纸包读取、预览、选择下载和本地缓存。
- 默认只读取并下载静态贴纸，避免动态贴纸和视频贴纸在键盘环境中造成不稳定。
- 支持同名贴纸包重新添加时追加合并，不再覆盖已有贴纸。
- 支持删除贴纸、删除空贴纸组，并同步清理本地贴纸目录。
- 键盘支持按贴纸组切换、最近使用分组、左右滑动切换分组。
- 键盘贴纸点击后复制图片到剪贴板，并保留系统键盘切换、回到主界面和指定脚本切换按钮。
- 设置页用于配置 Bot Token 和可选的目标键盘脚本名称。
- 已移除 ShareSheet 相关实验逻辑。

## 说明

- 动态贴纸功能默认关闭；开启后支持将 Telegram `.webm` 视频贴纸转换为 GIF。
- Telegram `.tgs` 是 Lottie 矢量动画，FFmpeg 无法直接解析，当前不会导入。
- iOS 自定义键盘无法稳定把图片或文件直接粘贴到宿主 App 光标处，当前采用复制到剪贴板的方式。

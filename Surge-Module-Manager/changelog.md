## v3.1.0
- 修正设置页底部滚动模糊层，HTTP 远程控制使用可拖动的 Sheet。
- 新增订阅提交后立即收起 Sheet，下载进度与错误显示在订阅列表页。
- 模块和订阅删除仅接受明确确认；取消时不再执行删除。
- 底栏新增设置标签；长按设置进入 HTTP 远程控制 Sheet。模块、订阅标签长按可打开搜索和批量操作。
- 订阅列表支持实时搜索、批量选择、更新与删除。
- 修复模块和订阅滑动删除在二次确认前先移除列表行、取消时可能闪退的问题。
- 删除订阅时可选择保留或同时删除对应的 `.dconf` 文件。
- 缩小添加订阅时标题与输入框的间距。
- 底部恢复原有 LiquidDock 样式，修复长按触摸层被按钮遮挡、切换页面时底栏被卸载的问题；移除模块页底部多余的滚动边缘模糊层。
- 模块行仅显示分类与本地/远程图标；两个列表统一为分组卡片，行内容左对齐，分割线从卡片左侧开始。
- 重做模块与订阅双页布局：顶部固定信息汇总，模块分类通过独立的原生玻璃按钮横向切换并完整显示名称。
- 移除列表末尾的占位卡片；模块行分类改为无底色的次要文字。
- 订阅页支持一次更新全部订阅；保留单条更新、编辑、删除入口。
- 新增订阅改用底部 Sheet，名称同时作为新文件名；长按订阅可在非全屏 Editor 中编辑保存的文件。模块查看也改为非全屏 Editor。
- 机场订阅支持自定义 SNI/IP 服务、HTTP 429 限流等待和 Clash flow 风格节点。
